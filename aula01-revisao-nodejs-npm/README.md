# 📚 Aula 01 — Revisão do Node.js e NPM
# 📌 Objetivo da aula
Nesta aula foi realizada uma revisão dos conceitos fundamentais de Node.js e NPM, com foco na utilização do Node.js no desenvolvimento Server-Side.

Durante a aula, foram aplicados conceitos relacionados à configuração do ambiente, inicialização de um projeto e criação de scripts utilizando JavaScript no lado do servidor.

# 🟢 1. Node.js no Server-Side
O Node.js permite executar JavaScript fora do navegador, possibilitando o desenvolvimento de aplicações no lado do servidor (Server-Side).

Com ele, podemos criar APIs, servidores web, aplicações back-end, scripts e diversas outras soluções.

Nesta aula, foi utilizado o Node.js para acessar informações do computador por meio de módulos nativos.

✅ Criação de um arquivo JavaScript
✅ Execução de scripts com Node.js
