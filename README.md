# codificacao-back-end
Projeto voltado ao desenvolvimento de aplicações e serviços de Back-End, com foco em organização, implementação de regras de negócio, APIs e integração com bancos de dados.

# 📌 Sobre o projeto
O codificacao-back-end reúne os códigos e recursos utilizados no desenvolvimento Back-End, servindo como base para estudos, exercícios e implementação de funcionalidades relacionadas ao lado do servidor de uma aplicação.

# 🛠️ Tecnologias
As principais tecnologias utilizadas neste projeto são:
Back-End
APIs REST
Banco de dados
Git e GitHub
Linguagem de programação utilizada no projeto
