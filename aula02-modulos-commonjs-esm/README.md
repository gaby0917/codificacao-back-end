# 📋 Sistema de Logs com Node.js
Este projeto apresenta um sistema simples de registro de logs desenvolvido com Node.js. 🚀
O objetivo é registrar mensagens importantes durante a execução de uma aplicação, facilitando o acompanhamento de eventos e possíveis erros. 🔎

# ⚙️ Funcionamento
O sistema recebe mensagens e armazena cada registro em um arquivo de log. 📄
Os registros são organizados dentro de uma pasta específica chamada logs. 📁
Cada mensagem recebe automaticamente a data e o horário em que o evento aconteceu. 🕐
Além disso, novos registros são adicionados ao arquivo sem apagar os registros anteriores, mantendo todo o histórico da aplicação. 📝

# ✨ Funcionalidades
📝 Registro de mensagens do sistema
📁 Criação automática da pasta de logs
📄 Armazenamento dos registros em um arquivo
🕐 Inclusão automática de data e horário
💾 Preservação do histórico de registros
⚠️ Tratamento de possíveis erros

# 🎯 Objetivo
O projeto tem como finalidade praticar conceitos fundamentais do Node.js, como:
📦 Utilização de módulos
📂 Manipulação de arquivos e diretórios
⏳ Operações assíncronas
🛠️ Tratamento de erros
🗂️ Organização de informações em arquivos de log

# ✅ Resultado
Ao executar a aplicação, as mensagens informadas são registradas automaticamente no arquivo de log, acompanhadas da data e do horário. 🕐
Dessa forma, é possível acompanhar de maneira simples e organizada os acontecimentos durante a execução do sistema. 🚀
